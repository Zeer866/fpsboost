## Cómo descargar el mod desde GitHub

Necesitas una cuenta de GitHub (es gratis). Sin iniciar sesión no deja descargar.

### Desde el celular

1. Abre este repositorio en el navegador e inicia sesión.
2. Toca la pestaña **Actions**. Si no la ves, desliza la barra de pestañas hacia el lado.
3. Toca la ejecución de más arriba que tenga una palomita verde. Si tiene una X roja, no la uses: elige otra verde.
4. Toca **Summary** (arriba a la izquierda) y baja hasta el final, a la sección **Artifacts**.
5. Toca **Build Output**. Se descarga un archivo zip.
6. Abre tu gestor de archivos, busca el zip en Descargas, tócalo y elige **Extraer**.
7. Dentro vas a encontrar el archivo **zeer866.fpsboost.geode**. Ese es el mod.

Si no ves la sección Artifacts, activa **Sitio para computadoras** en el menú del navegador y recarga la página.

### Desde la PC

1. Abre este repositorio e inicia sesión en GitHub.
2. Entra a la pestaña **Actions** y abre la ejecución de más arriba que tenga la palomita verde.
3. Baja hasta **Artifacts** y haz clic en **Build Output**.
4. Cuando termine de descargar, clic derecho al zip y **Extraer todo**.
5. Dentro está el archivo **zeer866.fpsboost.geode**.

El mismo archivo sirve para Android y para PC. Después sigue los pasos de instalación de tu dispositivo.
